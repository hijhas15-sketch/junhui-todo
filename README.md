# 하루 · 루틴과 할 일

휴대폰에 맞춰 만든 개인용 웹앱입니다. **index.html 하나로 동작**하고, 서버·로그인·설치 파일이 필요 없습니다.
GitHub Pages에 올려 두면 휴대폰에서 주소로 열고, **홈 화면에 추가(앱 설치)** 해서 네이티브 앱처럼 쓸 수 있습니다.

- 앱 주소: **https://hijhas15-sketch.github.io/junhui-todo/**
- 저장소: https://github.com/hijhas15-sketch/junhui-todo

## 들어 있는 것

| 탭 | 내용 |
|---|---|
| **루틴** | 매일·평일·주말·요일 지정 반복 / 날짜가 바뀌면 자동 초기화 / 연속 일수(🔥)와 최근 7일 기록 |
| **할 일** | 마감일·태그가 붙는 한 번짜리 체크리스트 / 지난 일은 붉게 표시 / 완료 모아서 지우기 |
| **공부** | D-DAY 배너 / 과목별 목표량·진행도·회독 기록 / 오늘 공부 체크 |

세 탭 모두 카드 오른쪽의 **손잡이(⠿)를 끌어 순서를 바꿀 수 있습니다**. 손가락 터치에 맞춘
포인터 이벤트 방식이라 안드로이드 크롬·삼성 인터넷에서 그대로 동작하고, 손잡이 바깥을
쓸면 평소처럼 화면이 부드럽게 스크롤됩니다. 바꾼 순서는 바로 저장되고, **할 일**은
완료한 일이 항상 아래에 모입니다.

오른쪽 위 톱니바퀴(⚙)에서 **JSON 내보내기 · 가져오기 · 샘플 데이터 · 전체 초기화**를 할 수 있습니다.

## 휴대폰에 앱으로 설치하기 (Android)

1. Chrome 또는 Samsung Internet에서 **https://hijhas15-sketch.github.io/junhui-todo/** 를 엽니다.
2. 오른쪽 위 메뉴(⋮) → **앱 설치** (또는 **홈 화면에 추가**)를 누릅니다.
3. 홈 화면에 남색 체크 아이콘이 생기고, 주소창 없이 전체 화면으로 열립니다.

- 두 번째 실행부터는 인터넷이 없어도 열립니다(서비스 워커 `sw.js`가 화면과 아이콘을 캐시).
- iPhone은 Safari의 **공유 → 홈 화면에 추가**를 쓰면 됩니다(전체 화면 앱으로 동작).

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 앱 전체 (화면·기능·저장 로직) |
| `manifest.webmanifest` | 앱 이름·아이콘·시작 주소·전체 화면 설정 (PWA 매니페스트) |
| `sw.js` | 오프라인 실행용 서비스 워커 (HTML은 네트워크 우선, 나머지는 캐시 우선) |
| `icon.svg`, `icon-192.png`, `icon-512.png` | 홈 화면 아이콘 |

## 데이터 보관

- 모든 기록은 이 브라우저의 저장소(`localStorage`, 키 `junhui_todo_v1`)에만 남습니다. 서버로 보내지 않습니다.
- 브라우저 기록/사이트 데이터를 지우면 함께 사라지므로, 가끔 **⚙ → JSON 내보내기**로 백업해 두세요.
- 백업 파일은 `todo-backup-YYYY-MM-DD.json` 이름으로 내려받아지고, **가져오기**로 그대로 복원됩니다(현재 데이터는 덮어씀).
- 휴대폰을 바꿀 때도 이 파일 하나만 옮기면 됩니다.

## 고칠 때

`index.html`을 수정해 `main` 브랜치에 올리면 GitHub Pages가 1~2분 안에 자동 반영합니다.
서비스 워커는 HTML을 네트워크에서 먼저 받아오므로, 새로고침만 하면 최신 화면이 뜹니다
(캐시 이름을 바꾼 경우 `sw.js`의 `CACHE_NAME`을 올려 주세요).

## 참고

- 삭제·초기화·회독 마무리는 확인 창을 한 번 거칩니다.
- 파일로(`file://`) 직접 열어도 동작하지만, 브라우저에 따라 저장이 제한될 수 있어 주소로 여는 쪽을 권합니다.
